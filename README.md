# TMX CoCo hands-on lab guide

Attendee guide for a two-hour virtual lab that uses Cortex Code (CoCo) in Snowsight to explore daily stock prices from Snowflake Curated Data (Free), write and validate SQL, and build and deploy a Streamlit in Snowflake app.

This repo holds only the public, attendee-facing instructions. It contains no credentials, account details or data.

Run locally:

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
